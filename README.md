# Number Guessing Game (Java)

A simple number guessing game built using Java as a part of the CodSoft Java Development Internship (Task1).

## Features
- A random number is generated within a range of 1-100.
- The player is asked to guess the number.
- The program will indicate if the player's guess is too high, too low, or correct.
- The player has a limited number of attempts to guess the number.
- The players can play multiple rounds of the game.
- The score of the player is tracked and displayed.

## How to Run
To compile and run the code, follow the below steps:
1. To compile the code: `javac TestGuessGame.java`
2. To run the code: `java TestGuessGame`

## Concepts Used
- Classes and Objects
- Methods and return type
- While loops and conditional statements
- Random and Scanner class
